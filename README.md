# 🎮 Pou Game Database Design

## 📌 Project Overview

This project focuses on designing a relational database for a Pou-inspired virtual pet game. The database models player accounts, virtual pet information, pet status, game items, mini-games, and game session records.

## 🎯 Project Objectives

- Design a relational database structure for a virtual pet game.
- Define primary keys and foreign key relationships.
- Organize game-related information into related tables.
- Create sample data for database testing.

## 🗂️ Database Schema

The database consists of seven main tables:

1. **Player** — Stores player information.
2. **Pou** — Stores virtual pet information.
3. **StatusPou** — Stores the status and condition of each Pou.
4. **Item** — Stores available game items.
5. **ItemPou** — Connects items with Pou.
6. **MiniGame** — Stores mini-game information.
7. **GameSession** — Stores game session records.

## ⚙️ Features

- Relational database design.
- Primary key and foreign key relationships.
- Structured game data management.
- Sample records for database testing.
- Entity Relationship Diagram (ERD) for database visualization.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `poudatabase.sql` using a database management tool that supports the SQL syntax used in the file.
3. Execute the SQL script to create the database tables and insert the sample records.
4. Open `pou_game_sample_data.xlsx` to review the sample dataset.
5. Refer to `ERD POU.jpg` to understand the relationships between tables.
