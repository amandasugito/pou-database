# Pou Game Database Design

## Project Overview
This project focuses on designing a relational database for a Pou-inspired virtual pet game. The database models player accounts, Pou status, items, mini-games, and game session records.

## Objectives
- Design a relational database structure.
- Define primary keys and foreign key relationships.
- Organize game-related data into related tables.
- Provide sample data for database testing.

## Database Schema
The database consists of seven main tables:

1. **Player** — stores player information.
2. **Pou** — stores virtual pet information.
3. **StatusPou** — stores the pet's status.
4. **Item** — stores available game items.
5. **ItemPou** — connects items with Pou.
6. **MiniGame** — stores mini-game information.
7. **GameSession** — stores game session records.
